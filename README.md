# Matchday Ticket Watcher

`bookmarklet.js` is the current build of a personal bookmarklet that watches a
football club's Ticket Exchange for returned tickets. This repository exists only
so the small loader bookmarklet has a public address to download the newest build
from — `raw.githubusercontent.com` and jsDelivr only serve public repositories.

Nothing here is configuration, credentials or personal data. The file is the same
code that would otherwise be pasted into a bookmark by hand.

Source, history and tests live elsewhere; this is a publish target.
